# Data Classification and Handling

## Mandatory Training for Sagehen HPC Users

This workshop teaches Pomona College's three-tier data classification system and provides hands-on guidance for implementing proper security controls on the Sagehen HPC cluster. Completion is mandatory for all users storing research data.

## Key Information

- **Duration:** Approximately 6 hours (typically 2 sessions)
- **Requirement:** Mandatory for all users storing data on Sagehen HPC
- **Format:** Carpentries Workbench with hands-on exercises
- **Contact:** its-hpc@pomona.edu

## What This Training Covers

- Your responsibilities as a researcher handling data on Sagehen
- Pomona's three-tier data classification system (Public, Proprietary, Restricted)
- How to classify your research data correctly
- Handling requirements and security controls for each tier
- Storage and encryption using gocryptfs for Restricted data
- Safe sharing and collaboration practices
- How to report data security incidents

## Topics Included

1. Why Classify Data (15 min)
2. Three Tiers (30 min)
3. Classifying Your Data (30 min)
4. Handling Requirements (25 min)
5. Storage and Encryption (35 min)
6. Sharing and Collaboration (30 min)

## Prerequisites

- Active Pomona College account
- Access to Sagehen HPC cluster (or access to workshop recordings if async)
- Basic familiarity with your research data

## How to Use This Training

1. Work through each episode in order
2. Read all material carefully
3. Complete the hands-on exercises
4. Classify your data using Episode 03's decision tree
5. Set up encryption if you handle Restricted data
6. Document your classification decisions for audit purposes
